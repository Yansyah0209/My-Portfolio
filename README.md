# Kika Portfolio — recovered editable website

Static HTML/CSS/JavaScript source reconstructed from a published browser snapshot. **Not the original ChatGPT Sites React source.**

## Preview locally

Run `python -m http.server 8000` in this folder, then open http://localhost:8000.

## GitHub + Vercel

Upload all files in this folder to the root of the GitHub repository, including `index.html` and `assets/`. In Vercel, import that repository; set Framework Preset to **Other**, with no build command, and output directory `.`.

## Known limitations

- Original editable ChatGPT Sites components are not available.
- CV .docx is linked to the original website because its file was not in the snapshot.
- ARUNA research paper now links to its journal DOI rather than a missing local PDF.
- Browser snapshot animations and responsive behavior need comparison against the original site.
